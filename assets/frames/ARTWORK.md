# Halloween Snap V1.05 Frame Artwork

All six new transparent illustration overlays were created specifically for Halloween Snap, inspired by the *genre* of elaborately decorated Halloween photo frames on the user-linked Magnific/Freepik gallery. No stock frame was downloaded or embedded.

Frame IDs intentionally remain `bats`, `web`, `pumpkins`, `ghosts`, `witches`, and `skulls` for compatibility with older stored photos, and optional aspect-ratio variants use the same core artwork.

Files are WebP with true alpha transparency. For portrait and story variants, corner designs retain their proportions while less-detailed center edge regions are vertically extended. WebP requires iOS Safari 14+ / modern browsers.

The existing SVG illustrations and Font Awesome attribution files remain for historic compatibility but are not loaded by V1.05.
